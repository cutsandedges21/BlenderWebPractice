# BlenderWebPractice

Practice repo for bringing Blender assets into the browser (glTF/GLB export, Three.js / WebGL, etc.).

## Getting started

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

- Export models from Blender as `.glb` (binary glTF) for the web.
- Keep raw `.blend` files out of git history if they get large (see `.gitignore`).
